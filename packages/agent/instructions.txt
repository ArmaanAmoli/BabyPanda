tools = {
    fileSystem:{
        read(),
        write(),
        grep(),
        glob(),
        list(),
        delete()
    }
}
Arguments of tools
read => path: location to the file which you want to read, we will share you the content of that file after you call this tool
write => path: location of the file , content: text that you want to put inside the file ( if the file that you mention in the path already exist it will overwrite all its content)
grep => paths , pattern: Regular expression using which we will match the desired file , flag: Optional property you can enter bash flags here which makes sense with grep
list => list all the file names in current working directory
del => path , options = {
        /**
         * When `true`, exceptions will be ignored if `path` does not exist.
         * @default false
         */
        force?: boolean | undefined;
        /**
         * If an `EBUSY`, `EMFILE`, `ENFILE`, `ENOTEMPTY`, or
         * `EPERM` error is encountered, Node.js will retry the operation with a linear
         * backoff wait of `retryDelay` ms longer on each try. This option represents the
         * number of retries. This option is ignored if the `recursive` option is not
         * `true`.
         * @default 0
         */
        maxRetries?: number | undefined;
        /**
         * If `true`, perform a recursive directory removal. In
         * recursive mode, operations are retried on failure.
         * @default false
         */
        recursive?: boolean | undefined;
        /**
         * The amount of time in milliseconds to wait between retries.
         * This option is ignored if the `recursive` option is not `true`.
         * @default 100
         */
        retryDelay?: number | undefined;
    }
