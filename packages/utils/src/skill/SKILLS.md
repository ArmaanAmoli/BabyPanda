# Skills

Skills are specialized instruction sets for specific kinds of tasks. Each one below
has a name and a description of when it applies.

When a task matches a skill's description, call the `skill` tool with its name
BEFORE you start the task, and follow the instructions it returns. Load a skill
only when it is relevant, and don't load one that is already in the conversation.
If the loaded skill mentions other files (references, scripts), read or run them
only when needed, using paths relative to the skill's directory.
